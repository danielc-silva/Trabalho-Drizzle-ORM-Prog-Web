## Como rodar o projeto

1. Primeiramente, crie o banco de dados e a tabela que está no arquivo `banco-animais.sql`.
2. No terminal, entre na pasta `api-animais-drizzle`.
3. Execute o comando para instalar as dependências:
   ```bash
   npm i
4. Inicie o servidor da API:
   ```bash
   npm start
5. A API vai rodar em http://localhost:3000 e você já pode testar as devidas rotas pelo Postman ou outro software de sua escolha.
